# 🌐 Site Helper

یه اسکریپت تک‌فایلی پایتون که چند تا چک ساده و مفید روی هر سایتی انجام می‌ده — بدون نیاز به هیچ پوشه یا تنظیمات پیچیده‌ای.

## قابلیت‌ها

- ✅ بررسی آنلاین بودن سایت و اندازه‌گیری زمان پاسخ
- 📄 استخراج عنوان (title) و توضیحات متا (meta description)
- 🖼️ پیدا کردن تصاویر بدون `alt` (مهم برای SEO و دسترسی‌پذیری)
- 🔗 پیدا کردن لینک‌های خراب (broken links) توی صفحه

## نصب

```bash
pip install requests beautifulsoup4
```

## استفاده

```bash
python site_helper.py example.com
```

یا با آدرس کامل:

```bash
python site_helper.py https://example.com
```

## نمونه خروجی

```
🔎 در حال بررسی: https://example.com
----------------------------------------
✅ سایت آنلاینه — کد وضعیت: 200
⏱️ زمان پاسخ: 0.34 ثانیه

📄 عنوان صفحه: Example Domain
⚠️ توضیحات متا (meta description) تنظیم نشده — برای SEO بد نیست اضافه کنی.

🖼️ تعداد کل تصاویر: 0
✅ همه‌ی تصاویر alt دارن.

🔗 تعداد لینک‌های پیدا‌شده: 1 (در حال چک کردن 1 تای اول...)
✅ هیچ لینک خرابی (تو 20 تای بررسی‌شده) پیدا نشد.
----------------------------------------
🏁 بررسی تموم شد.
```

## نیازمندی‌ها

- Python 3.7+
- `requests`
- `beautifulsoup4`
